# 🌟 Ajwaa - Your AI Fitness Companion

> Like Duolingo, but for your health and fitness journey

---

## 🎯 Core Concept

**Ajwaa** is a personal AI fitness companion that teaches you healthy habits through:
- **Daily micro-lessons** (2-5 minutes)
- **Streaks & XP system**
- **Friendly AI mascot** guiding your journey
- **Bite-sized challenges**
- **Personalized learning path**

---

## 🤖 Meet "Jawa" - Your AI Companion

```
     ╭──────────╮
     │  ◕  ◕   │   "Hey! Ready for today's
     │    ◡    │    nutrition lesson? 🥗"
     ╰──────────╯
        /    \
```

**Jawa** is your encouraging, knowledgeable fitness buddy who:
- Greets you daily with personalized messages
- Celebrates your wins with animations
- Gently reminds you when you miss a day
- Adapts tone based on your progress
- Speaks Arabic & English naturally

## 📚 Lesson Types (Duolingo-Style)

### 1. **Swipe Cards** - Quick learning
```
┌─────────────────────────────────────┐
│  Which has more protein?           │
│                                     │
│  ┌─────────┐      ┌─────────┐      │

│  │ 2 Eggs  │  OR  │ 2 Bread │      │
│  └─────────┘      └─────────┘      │
│                                     │
│         Swipe left or right         │
└─────────────────────────────────────┘
```

### 2. **Fill in the Blank**
```
┌─────────────────────────────────────┐
│  To lose weight, you need to be    │
│  in a caloric _________.           │
│                                     │
│  [ deficit ]  [ surplus ]          │
│  [ balance ]  [ macro   ]          │
└─────────────────────────────────────┘
```

### 3. **Match Pairs**
```
┌─────────────────────────────────────┐
│  Match the food to its macro:      │
│                                     │

│  🍚 Rice       ──→    Carbs        │
│  🥑 Avocado    ──→    Fat          │
└─────────────────────────────────────┘
```

## 🎮 Gamification System

### XP (Experience Points)
| Action | XP Earned |
|--------|-----------|
| Complete lesson | +10 XP |
| Perfect score | +5 bonus |
| Daily workout | +20 XP |
| Log a meal | +5 XP |
| Maintain streak | +10 XP/day |
| Weekly goal | +50 XP |

### 🔥 Streaks
- **Streak Freeze** ❄️ - Protect your streak (earn or purchase)
- **Streak Society** - Milestone rewards at 7, 30, 100, 365 days
- **Comeback Bonus** - Extra XP when returning after missed days

### 🏆 Leagues & Leaderboards
```
┌─────────────────────────────────────┐
```

### 💎 Gems & Rewards
- Earn gems through challenges
- Spend on: streak freezes, power-ups, Jawa outfits
- Unlock special themed lessons

## 🛠️ Tech Stack Recommendation

### For Mobile-First (Recommended)
```
📱 React Native + Expo
├── Cross-platform (iOS + Android)
├── Fast development
├── Native feel
└── Easy animations (Reanimated)

🔥 Firebase
├── Authentication
├── Firestore (user data)
├── Cloud Functions (AI logic)
└── Push Notifications

🤖 AI Integration
├── OpenAI API (personalized coaching)
├── Gemini API (food recognition)
└── Custom prompts for Jawa personality
```

### For Web PWA (Quick MVP)
```
⚡ Vite + React
├── Fast builds
├── PWA installable
└── Works offline

📦 Zustand (state)
💾 IndexedDB (local storage)
☁️ Supabase (backend)
```
